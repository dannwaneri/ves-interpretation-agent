# web/

A small demo site for judges. Static only so far, no build step, no dependencies.

- `index.html` — landing page, one purpose line, links out.
- `findings.html` — the 10 internal inconsistencies from [`docs/conflicts-checklist.md`](../docs/conflicts-checklist.md), presented as cards, plus a collapsible table of all 11 Context Issues. Data is inlined as a small JS array at the bottom of the file, generated by hand from the checklist, not fetched live.
- `style.css` — shared styling, dark by default, light via `prefers-color-scheme`.

## Local preview

No build step needed:

```bash
npx serve web
```

## Deploy

Not yet deployed. Plan is Vercel, one project covering this static site plus a `/api` function (to be added) that calls `agent/index.js --offline` as a child process for an interactive question page. Deploy with your own Vercel account; this repo has none configured.

## Does not touch agent/

Nothing here imports or modifies any file under `agent/`. The planned interactive page will call the existing `--offline` CLI unchanged, as a child process from a Vercel serverless function, not by importing agent code into a bundle.
